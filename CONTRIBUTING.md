# Contributing to Trailboss

Thanks for helping.

## Where things go

- **Bugs and feature requests:** [issues in this repository](https://github.com/trailboss-ai/trailboss/issues), whichever part you think is at fault. The templates ask for what's needed.
- **Questions and ideas:** [Discussions](https://github.com/trailboss-ai/trailboss/discussions).
- **Security problems:** privately, see [SECURITY.md](SECURITY.md).
- **Code:** pull requests to the public repositories. Each has its own CONTRIBUTING with how to build and test it:
  - [trailboss-adapters](https://github.com/trailboss-ai/trailboss-adapters): support for a new agent, a fix for a changed transcript format, a new terminal app;
  - [trailboss-herdr](https://github.com/trailboss-ai/trailboss-herdr): the Herdr mod;
  - [trailboss-specification](https://github.com/trailboss-ai/trailboss-specification): the JSON formats.

  Link the issue here from your pull request. The CLI's core isn't public, so changes there are made by the maintainer, from an issue.

## Never include

Real transcripts, tokens or credentials, in issues, logs or pull requests. Agents' transcripts hold code, secrets and personal data: describe the problem, or make a small synthetic example.
